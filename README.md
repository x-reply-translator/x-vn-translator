# X 베트남어 번역기

X(트위터)에서 쓰는 크롬 확장이에요. 기존 [X 댓글 번역기](https://github.com/x-reply-translator/x-reply-translator)와는 **별개**이고, 그 저장소는 그대로 둡니다.

- **댓글 번역:** 댓글창에 베트남어로 쓰고 `한국어로`·`영어로`·`중국어로` 버튼을 누르면 초안이 그 언어로 바뀌어요. 언어는 버튼을 다시 눌러 바꿀 수 있어요. 답글 다는 글의 분위기를 보고 공지·정중한 글엔 정중하게, 밈·드립 글엔 현지 인터넷 말투로 맞춰요.
- **본문 해석:** 베트남어 글 위에 `한국어`·`영어`·`중국어` 버튼이 붙어요. 누르면 직역투 없이 자연스럽게 해석하고, 다른 버튼을 누르면 언어가 바뀌어요.
- 게시 버튼은 절대 누르지 않아요. 바뀐 글을 확인하고 직접 올리면 돼요.

## 설치

1. 이 저장소를 내려받아요 (`Code` → `Download ZIP` 후 압축 풀기).
2. 크롬(또는 브레이브·엣지) 주소창에 `chrome://extensions` 를 열어요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램을 로드** → `extension` 폴더를 골라요.
5. 툴바의 확장 아이콘(파란 "번")을 누르면 설정 창이 떠요. AI 서비스·모델·API 키를 넣고 저장해요. (기존 번역기와 설정이 분리되어 있어서, 키는 여기에 따로 넣어야 해요.)
6. X 탭을 새로고침해요.

기존 「X 댓글 번역기」와 같이 써도 돼요. 이 확장은 베트남어 글·초안에만 버튼을 붙입니다.

## API 키

내 API 키로 동작해요. 키는 내 브라우저(`chrome.storage.local`)에만 저장되고, 설정한 API 주소로만 보내져요.

| 서비스 | API 주소 | 모델 예시 |
|---|---|---|
| Anthropic | (자동) | `claude-haiku-5-5` |
| OpenAI | `https://api.openai.com/v1` | 원하는 모델 이름 |
| OpenRouter | `https://openrouter.ai/api/v1` | 원하는 모델 이름 |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |

빠르고 싼 모델이면 충분해요. 댓글 하나 번역에 보통 몇 원 정도예요.

## 알아 둘 것

- 번역할 글(내 초안과 답글 다는 글 본문)이 설정한 AI 서비스로 보내져요. 그 밖의 곳으로는 아무것도 보내지 않아요.
- X 화면 구조가 바뀌면 버튼 위치가 깨질 수 있어요.
- 한 번에 2,000자까지 번역해요.
